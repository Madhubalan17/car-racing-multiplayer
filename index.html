📖 HOW TO PLAY & RUN SERVER

🎮 Game Rules & Tips

  • Dodge traffic cars to avoid slowing down from crashes!
  • Passing close to traffic cars without hitting them awards bonus Nitro!
  • Hold [W] / [Space] / [▲] to burn Nitro and reach 280+ km/h!
  • First player to cross the finish line wins the race!

🚀 How to Run the Server (Local & LAN)

node server.js

Then open in your browser:

  • Local: http://localhost:8080
  • Play on Mobile or with Friends on same Wi-Fi: use the LAN address printed in terminal (e.g. http://192.168.1.X:8080)!
  • Or run with Python: python -m http.server 8080
  • Or use VS Code Live Server!
